# Sales & Revenue Analysis Dashboard

## Project Overview
This project is a Sales & Revenue Analysis Dashboard created using Power BI. It helps analyze sales performance, revenue trends, and top-performing products.

## Tools Used
- Power BI
- Microsoft Excel
- Data Visualization
- DAX

## Key Features
- Total Sales analysis
- Revenue analysis
- Sales trends
- Top-performing products
- Interactive charts
- Filters and slicers

## Project Objective
The objective of this project is to analyze sales and revenue data and present useful business insights through an interactive dashboard.

## Outcome
This project demonstrates skills in data visualization, KPI tracking, dashboard development, and business insight generation.
